Results file format

Any object keyed by site code works. Supported shapes:

{
  "name": "Extinction risk",
  "unit": "probability",
  "steps": ["2026", "2050", "2100"],
  "data": {
    "1.1.2": [0.11, 0.24, 0.61],
    "1.1.3": [0.08, 0.19, 0.55]
  }
}
// per-site key/value metrics (no time axis)
{
  "name": "Simulation output",
  "data": {
    "1.1.2": { "risk": 0.31, "population": 4200 },
    "1.1.3": { "risk": 0.22, "population": 9800 }
  }
}

CSV: CODIGO,step,value (long) or CODIGO,metricA,metricB (wide).

Programmatic: window.GuadeX.setResults(obj), window.GuadeX.loadResults(url), window.GuadeX.selectSite("1.1.2").

Data provenance

1,037 sampling sites and the catchment/river/reservoir geometry come from the GuadeX GIS archive (EPSG:25830, ETRS89 / UTM 30N). Relief is interpolated (IDW) from the 776 sites that carry an altitude, masked to the catchment union — it is an aid to reading the landscape, not a survey DEM.
